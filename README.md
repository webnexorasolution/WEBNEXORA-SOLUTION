# Webnexora Solution 🌐✨

A modern, high-performance website design and digital agency web application crafted with **React (Vite)**, **Vanilla CSS**, and **Three.js 3D animations**.

Inspired by [webnovaindia.com](https://webnovaindia.com/) and fully customized for **Webnexora Solution**.

---

## 🚀 Features

- **3D Interactive Hero Experience**: Three.js floating distorted spheres, starfield particle constellation, wireframe tori, and interactive mouse parallax.
- **3D Flip Cards (Services)**: 6 core digital services with interactive CSS 3D perspective flip (`rotateY(180deg)`), detailed feature lists, and direct CTA actions.
- **3D Torus Banner (Why Choose Us)**: Custom Three.js interactive rotating metallic torus, wireframe accents, and glowing particle ring.
- **Project Showcase (Portfolio)**: High-resolution showcase covering Business, E-Commerce, and Portfolio categories.
- **4-Step Work Process**: Discover, Plan & Design, Build & Review, and Launch phases with clear visual connectors.
- **Interactive WhatsApp Integration**: Direct lead generation form pre-populating WhatsApp messages for quick customer inquiries.
- **Responsive & Accessible**: Optimized for desktop, tablet, and mobile with glassmorphism design system, smooth scrolling, and dark theme aesthetics.

---

## 🛠️ Tech Stack

- **Frontend**: [React 18 / 19](https://react.dev/), [Vite](https://vitejs.dev/)
- **Styling**: Vanilla CSS (Custom Design System, Glassmorphism, CSS 3D Transforms)
- **3D Graphics**: [Three.js](https://threejs.org/)
- **Icons**: Custom SVG & Unicode geometric glyphs
- **Typography**: [Google Fonts (Syne & Inter)](https://fonts.google.com/)

## 💻 Getting Started Locally

### 1. Clone the repository
```bash
git clone https://github.com/webnexorasolution/webnexora-solution.git
cd webnexora-solution
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 4. Build for production
```bash
npm run build
```
